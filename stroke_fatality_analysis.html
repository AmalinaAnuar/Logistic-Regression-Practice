1 Introduction & Study Overview

This analysis investigates independent clinical and demographic factors associated with stroke fatality (outcome) using logistic regression in R. The study uses the dataset stroke-fatality-cooked2.dta (226 observations, 22 variables).

1.1 Statistical Assumptions

  1. Binomial distribution for the binary outcome (0 = alive, 1 = dead).
  2. Linearity in the logit for continuous independent variables.
  3. Correct model specification without omission of critical confounders.

4 Univariable Logistic Regression Analysis

We fit simple logistic regression models for each of the 20 candidate independent variables against outcome_num. Variables with a Wald test p-value \(< 0.25\) are selected as candidates for the multivariable model.

Code 
iv_vars <- c("sex", "gcs", "sbp", "dbp", "hr", "hb", "plat", "wbc",
             "na", "potas", "cbs", "urea", "age",
             "hypertension", "maritalstat", "malay", "diabetes",
             "dyslipidaemia", "referralcase", "stroketype")

univar_results <- map_dfr(iv_vars, function(var) {
  form <- as.formula(paste("outcome_num ~", var))
  fit <- glm(form, data = stroke_df, family = binomial)
  
  tidy(fit, conf.int = TRUE, exponentiate = FALSE) %>%
    filter(term != "(Intercept)") %>%
    mutate(
      variable    = var,
      log_odds    = estimate,
      OR          = exp(estimate),
      OR_lower    = exp(conf.low),
      OR_upper    = exp(conf.high)
    ) %>%
    dplyr::select(variable, term, log_odds, std.error, OR, OR_lower, OR_upper, p.value)
})

# Display candidate table
univar_results %>%
  mutate(
    Selected_Candidate = if_else(p.value < 0.25, "Yes (p < 0.25)", "No"),
    across(c(log_odds, std.error, OR, OR_lower, OR_upper), ~ round(., 3)),
    p.value = if_else(p.value < 0.001, "< 0.001", sprintf("%.3f", p.value))
  ) %>%
  gt() %>%

    p.value = "p-value",

  )

# Introduction & Study Overview

This analysis investigates independent clinical and demographic factors associated with stroke fatality (`outcome`) using logistic regression in R. The study uses the dataset `stroke-fatality-cooked2.dta` (226 observations, 22 variables).

## Statistical Assumptions

1. **Binomial distribution** for the binary outcome (`0 = alive`, `1 = dead`).
2. **Linearity in the logit** for continuous independent variables.
3. **Correct model specification** without omission of critical confounders.

# Univariable Logistic Regression Analysis

We fit simple logistic regression models for each of the 20 candidate independent variables against `outcome_num`. Variables with a Wald test p-value $< 0.25$ are selected as candidates for the multivariable model.

```{r}
#| label: univariable-regression
iv_vars <- c("sex", "gcs", "sbp", "dbp", "hr", "hb", "plat", "wbc",
             "na", "potas", "cbs", "urea", "age",
             "hypertension", "maritalstat", "malay", "diabetes",
             "dyslipidaemia", "referralcase", "stroketype")

univar_results <- map_dfr(iv_vars, function(var) {
  form <- as.formula(paste("outcome_num ~", var))
  fit <- glm(form, data = stroke_df, family = binomial)
  
  tidy(fit, conf.int = TRUE, exponentiate = FALSE) %>%
    filter(term != "(Intercept)") %>%
    mutate(
      variable    = var,
      log_odds    = estimate,
      OR          = exp(estimate),
      OR_lower    = exp(conf.low),
      OR_upper    = exp(conf.high)
    ) %>%

})
```

## Summary of Findings

1. **Glasgow Coma Scale (`gcs`)**: Strongest independent protective factor ($\text{AOR} = 0.489$, $95\%\text{ CI: } 0.396 - 0.588$, $p < 0.001$). Higher consciousness at presentation substantially reduces the probability of stroke mortality.
2. **Patient Sex (`sex`)**: Female stroke patients had lower in-hospital mortality odds compared to male patients ($\text{AOR} = 0.327$, $95\%\text{ CI: } 0.100 - 0.945$, $p = 0.044$) after controlling for GCS.
3. **Discriminative Capacity**: The final model achieves outstanding discrimination ($\text{AUC} = 0.943$) and satisfactory calibration ($p = 0.099$).
